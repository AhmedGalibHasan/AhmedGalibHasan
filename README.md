# Hi, I'm Ahmed Galib Hasan

Final-year Computer Science & Engineering student at **BRAC University**. I build software and machine-learning projects that turn a concrete problem into something people can actually use: a model, an API, or an interactive application.

I work across **artificial intelligence**, **machine learning**, **software engineering**, and **cybersecurity**, with a preference for projects that connect research ideas to a working product.

## About

I like starting from a real constraint — a schedule that does not fit, a loan decision that needs evidence, a campus workflow that is scattered across tools — and shipping a system around it. Recent work spans graph and transformer models, full-stack web platforms, and real-time 3D graphics.

## What I work on

- **Machine learning and NLP.** Hybrid text-and-graph models, classical prediction pipelines, and notebook-driven experiments.
- **Full-stack applications.** REST APIs, authentication, and React interfaces for reading, campus, and event platforms.
- **Interactive systems.** Real-time 3D games with camera control, physics-style gameplay, and OpenGL rendering.
- **Reliable software.** Clear project structure, version control, and an interest in secure systems.
